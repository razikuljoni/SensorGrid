# Changelog

All notable changes to **SensorGrid** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-12

### Added

- **IoT Fleet Intelligence & Automation Platform** initial release.
- **Serverless SSE Engine** replacing legacy Socket.IO for Vercel edge/serverless compatibility.
- **Digital Twin Architecture** for desired vs reported device states.
- **Visual Flow Builder** for device automation rules using `@xyflow/react`.
- **Aether Grid Design System** with dark/light themes and responsive components.
- **Telemetry Explorer & Analytics** with live multi-sensor charts and trend visualization.
- **Alert & Command Management** with lifecycle states (Triggered/Ack/Resolved).
- **Prisma & SQLite/PostgreSQL** dual database configuration.
- **Vercel & Neon Integration** documentation and live deployment endpoints.
- **Developer Workflows**: Added GitHub Actions CI, linting, typechecking, Prettier formatting, auto changelog generator, and issue templates.
