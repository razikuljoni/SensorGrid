   251→# 6. UNIQUE DESIGN SYSTEM
   252→
   253→# Design System Name
   254→
   255→## **Aether Grid**
   256→
   257→Aether Grid is the complete visual language of Nexora Pulse.
   258→
   259→Its philosophy:
   260→
   261→> Data should feel alive, but never noisy.
   262→
   263→The design is built around invisible structure, soft surfaces, precise spacing, and meaningful motion.
   264→
   265→---
   266→
   267→## 6.1 Visual Principles
   268→
   269→### Principle 1 — Atmospheric Minimalism
   270→
   271→Interfaces should breathe.
   272→
   273→Use generous whitespace.
   274→
   275→Avoid dense borders everywhere.
   276→
   277→Use layered surfaces instead of boxed widgets.
   278→
   279→### Principle 2 — Signal Over Decoration
   280→
   281→Every color, icon, animation, and chart must communicate information.
   282→
   283→Nothing should exist purely as decoration.
   284→
   285→### Principle 3 — Physical Meets Digital
   286→
   287→Since this is an IoT platform, UI elements should subtly resemble instrumentation:
   288→
   289→- gauges
   290→- panels
   291→- indicators
   292→- telemetry
   293→- signal strength
   294→- pulses
   295→
   296→without looking like old industrial software.
   297→
   298→### Principle 4 — Motion Has Meaning
   299→
   300→Animations indicate:
   301→
   302→- incoming telemetry
   303→- successful commands
   304→- device reconnecting
   305→- automation execution
   306→- alerts
   307→
   308→Never animate continuously without purpose.
   309→
   310→---
   311→
   312→## 6.2 Color System
   313→
   314→Use semantic tokens only.
   315→
   316→### Base Surfaces
   317→
   318→```text
   319→Canvas
   320→Surface
   321→Surface Elevated

   334→```
   335→

   338→Create tokens.

   340→Example semantic tokens:
   341→
   342→```css
   343→--background
   344→--surface

   347→
   348→--primary
   349→--primary-hover
   350→--primary-muted
   351→
   352→--accent
   353→--accent-muted

   355→--success
   356→--warning
   357→--danger
   358→--info

   361→--border-subtle

   363→--text-secondary
   364→--text-muted

   366→
