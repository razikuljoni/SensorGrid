# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SensorGrid, please send an email to the security contact or open a confidential security advisory.

Please include:

- Description of the vulnerability and its potential impact
- Step-by-step instructions or PoC script to reproduce the issue
- Affected components or API endpoints

We will acknowledge receipt within 48 hours and work to resolve reported vulnerabilities promptly.
